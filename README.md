# radius-mockups

Mockup images for the radius-next brainstorm reviews ("Claude's take" Google Doc).
Public only so Google Docs can fetch and embed them; Docs keeps its own copy once inserted.

- `YYYY-MM-DD/<slug>.png` — one image per mockup
- `src/YYYY-MM-DD/<slug>/*.html` — the source artboards
- `scripts/render.py` — renders artboards side by side into one PNG (Playwright + Chromium)
